翻页器 / 按键侦听器 v1

本页只做一件事：把键盘收到的每一个按键原样打出来。2.4G 翻页器在系统里就是一个键盘， 按一下它的按钮，这里就会出现对应的键。
用法：点一下页面空白处让页面获得焦点 → 依次按翻页器的 5 个按钮 → 每个按钮按下后， 看下面「最后按键」里的 key 与 code 是什么。

按键统计里的「第 1 次按下」时间也能帮你对上哪个按钮是哪个。
如果某个按钮按下去这里毫无反应，说明它发的是系统媒体键（音量加/减、静音、播放/暂停）。 这类键由 Windows 直接吃掉去调音量，浏览器收不到键盘事件——这是系统层面的限制，不是网页写错了。 判断办法：按下去时看右下角音量条有没有动。会动 = 媒体键；不动且这里也没记录 = 需要另想办法（比如用厂商配的软件改键）。
想把音量键也一起确认：双击同目录的 「按键监听-系统级.cmd」（60 秒），它挂的是 Windows 全局键盘钩子， 连媒体键都能抓到，结果会打印并写进 按键记录.txt。
常见翻页器键值对照：上一页 PageUp／下一页 PageDown； 有些型号用 ArrowLeft/ArrowRight 或 B(黑屏)/F5 全屏。 如果那个「不知名按键」报的是 F5、Escape、B、Period， 基本就是全屏/黑屏键。
