# 智能提词器 · Teleprompter

单文件网页版提词器，双击即用、无需安装。支持 Word 讲稿、语音跟读自动滚动、逐行横滚「火车」式滑动、2.4G 翻页器接管。

**在线版（手机可用）：https://f1uke76.github.io/teleprompter/** —— https 托管，安卓 / iPhone 可直接用麦克风跟读。

> 所有版本都是**独立完整的单文件**，互不覆盖，可随时回退对比。

---

## 两种用法

| 场景 | 用哪个 | 说明 |
|---|---|---|
| 手机 / 平板 / 临时借用别人的电脑 | **在线版** <https://f1uke76.github.io/teleprompter/> | 不需要任何文件，https 打开即可用麦克风；iPhone 用 Safari、安卓用 Chrome |
| 自己的 Windows 电脑、现场无网 | 本地版 `index-v0.16.html` + `启动提词器(推荐-免反复授权).cmd` | 完全离线，功能与在线版一致 |

> 在线版与本地版**页面代码同源**，差别只在手机适配（自定义视口、工具栏横滑、安全区、屏幕常亮、iOS/安卓分别的权限引导）。

## 快速开始

推荐双击 **`启动提词器(推荐-免反复授权).cmd`**：

- 它会用系统自带 PowerShell 在 `127.0.0.1:8765` 起一个只监听本机的小静态服务，并自动用默认浏览器打开**版本号最高**的 `index-v*.html`
- 关键好处：用 `file://` 打开时浏览器把页面当成「一个文件」，**不持久化麦克风授权**，朗读中识别会话重启就会反复弹权限窗；走 `http://127.0.0.1` 后授权一次即可记住整场
- 黑色命令行窗口不要关（关掉即停服务，已打开的页面不受影响）

也可以直接用 Chrome / Edge 双击 `index-v0.16.html`，只是麦克风授权不能被记住。

**环境要求**：Windows + Chrome 或 Edge（在线语音识别依赖浏览器自带 `SpeechRecognition`，需联网）。

## 功能要点

### 讲稿

- 「打开文档」支持 `.docx` / `.txt`，也可粘贴文本或直接把文件拖入窗口
- 启动时自动载入同目录 `古诗词三首说课稿.docx`（取不到则用内置副本）
- 逐行横滚：按句号断行，**每句独占一行不换行**，句子从锚点开始像火车一样连续向左滑
- 短句自动与下一句拼接（最多 3 句、不跨段），可在锚点面板关闭

### 三种模式（可随时互切）

`▶ 自动滚动` / `🎤 在线跟读` / `🎧 离线跟读` 三者互斥，点哪个切哪个，**都从当前读到的位置接着走**（要回开头点 `↺ 复位`）。

- 自动滚动：速度 **2.0~7.0 字/秒**（7.0 = 满量程，4 左右≈正常朗读），滑块与数字框双向联动
- 词元化按字符对齐，**顿号、逗号也各算 1 个字**，标点密的句子不会突然变快
- 在线跟读：点按授权一次，之后朗读中不再申请麦克风；断线指数退避重连，60 秒最多 25 次后熔断等待点击
- 离线跟读：首次下载约 40MB 中文模型（vosk-browser），之后可断网

### 翻页器

顶部「🎮 翻页器」总开关，开启后绑定按键由提词器独占，不再触发浏览器滚动或 Tab 跳焦点；「⚙」进入按键设置。

**只有单击**：按下即生效（长按与双击已移除）。

| 按键 | 默认动作 | 可选动作 |
|---|---|---|
| PageUp（上一页） | 快进（字数可调，默认 12） | 快退 / 速度加减 / 开始暂停 / **切到语音跟读** / **切到自动滚动** |
| PageDown（下一页） | 快退 | 同上，任选 |
| 音量 + / − | 速度 ±0.1 字/秒 | 同上 |
| Tab | 开始/暂停自动滚动 | 同上 |

- **快进/快退是一段连续滑行**：按字符位置做 0.3~1.4 秒的缓入缓出动画，横向/纵向都跟着走，和朗读时的滑动是同一条路径，不会一格一格跳
- **上下翻页键可改成切模式**：把 PageUp 的动作选成「切到语音跟读」、PageDown 选成「切到自动滚动」，就跟朗读/滚动按钮一样互切，切换后对应按钮自动高亮
- 每个键都可单独启用、可「重绑」（点击后按新键，Esc 取消）、可清除；快进字数、音量步长、跟读方式（在线/离线）随配置一起导出导入

> 注意：**音量键通常被 Windows 自己吃掉**，网页可能收不到。若按了没反应属正常，用「重绑」改到别的键即可；要真正只在提词器内生效，需要系统层改键。

### 其他

- 鼠标**直接点正文里的任意一个字**即可跳转到该词，自动滚动/跟读会从新位置继续
- 锚点位置（上下 / 左右）、预滚量、语速跟随灵敏度可调，支持 `Alt + ↑↓←→` 微调
- 配置「⬇ 导出 / ⬆ 导入」JSON，含字体、字号、行距、速度、锚点、灵敏度、拼接、高亮、重连、翻页器绑定

### 快捷键

`空格` 自动滚动开关 · `↑/↓` 手动滚动 · `F` 全屏 · `R` 复位 · `Alt + ↑↓←→` 微调锚点

## 在线版怎么更新

1. 改 `index-online.html`
2. 双击 `build-online.cmd`（会把页面和 docx 同步进 `docs/`）
3. `git add -A && git commit -m "..." && git push`

GitHub Pages 监听 `main` 分支的 `/docs` 目录，推送后 1 分钟左右自动重建。

## 手机使用要点

- **iPhone**：只能用 **Safari**。点「🎤 在线跟读」→ 允许麦克风。Safari 的语音识别不支持长连续，程序靠「每句结束自动续上」，句间有零点几秒空档属正常；每次重启必须由点击触发，所以断线时提示「继续跟读」点一下即可。
- **安卓**：优先 **Chrome**（华为/小米自带浏览器多不支持语音识别）。
- 手机浏览器**只在 https 页面**给麦克风，用 http 或本地文件会被直接拦，页面顶部会提示。
- **别锁屏**：锁屏会断麦，页面在朗读时会自动申请 Wake Lock 保持亮屏。
- 想全屏无地址栏：Safari 分享 →「添加到主屏幕」；Chrome 菜单 →「添加到主屏幕」。

## 开发备注

- 工程是**单文件 HTML**：内联 CSS + JS，零外部依赖（docx 解析用 `DecompressionStream` + `<w:t>` 提取，不引入 JSZip）
- 每轮改动都**另存新版本**，旧版保留可对比，不做原地覆盖
- 滚动引擎关键设计：内部浮点 `scrollPos`（规避 `scrollTop` 取整吞位移）、词元坐标表 `ln.cxs` 做字符级插值、`anchorWordX` 固定锚点、`stepVertical` 一阶低通
- 验证方式：无头 Edge + CDP 注入键盘/语音桩，采样位移序列算停滞帧/回退帧/换行连续性
