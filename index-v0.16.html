使用说明

载入讲稿：「打开文档」支持 .docx 与 .txt；也可「粘贴文本」或直接把文件拖入窗口。

默认演示稿（v0.14）：启动时会自动载入同目录下的 古诗词三首说课稿.docx 作为演示稿；取不到磁盘文件时退回内置副本，不用手动打开。想换成自己的稿子，直接「打开文档」或拖进来即可。

翻页器（v0.16）：点顶部「🎮 翻页器」开启后，绑定过的按键只由提词器处理，不再触发浏览器滚动/翻页；点旁边的「⚙」可以改绑定、单独停用某个键。只保留单击（长按与双击已移除），按下即生效。默认：上一页 = 快进（字数可调，默认 12 字）、下一页 = 快退、音量 +/- = 滚动速度加减、Tab = 开始/暂停。快进/快退是连续滑过去的，不会一格一格跳：程序按字符位置做一段约 0.3~0.9 秒的缓入缓出滑动，和朗读时的滑动完全同一条路径。
上下翻页键可改成切模式：在「⚙」里把某一键的「动作」选成 切到语音跟读 或 切到自动滚动 即可 —— 例如上一页 = 切语音跟读、下一页 = 切自动滚动，切换后对应按钮会自动高亮；跟读用在线还是离线，在「⚙」的「跟读方式」里选。音量键由 Windows 处理、网页常常收不到，若按了没反应，用「重绑」换成别的键即可。

三种模式可随时互切（v0.14）：「▶ 开始（自动滚动）」「🎤 在线跟读」「🎧 离线跟读」彼此互斥——跟读中点了自动滚动，会立刻退出语音识别并切到自动滚动；跟读中点了另一种跟读，也会先退出前一种。三种方式都从当前读到的那一句接着走，不会回到开头（要回开头点「↺ 复位」）。

点击跳转（v0.14）：用鼠标直接点正文里的任意一个字，提词位置立刻跳到那个词上，正在自动滚动或跟读时也会从新位置继续。鼠标划过正文会变成手型；拖动选中文字时不会误跳。

显示调节：顶部可切换字体、字号、行距。字号与行距都是「滑块 + 数字框」两件套：拖滑块即时生效，也可以直接在数字框里敲精确值（回车或点别处生效），超出范围会自动纠正。字号 20~180 px，行距 1.1~2.4 倍。

滚动控制：「自动滚动」不是一整行一整行地往上跳，而是和语音跟读完全一样——当前句从锚点开始、像火车一样连续向左滑动，读到行尾再平滑换到下一行；同时当前词会高亮，进度也会走。速度单位是字/秒：2.0 ~ 7.0，7.0 就是满量程（2 偏慢、4 左右接近正常朗读、7 属于快速扫读；顿号、逗号等标点也各算 1 个字，所以句子里顿号多也不会突然变快）。滑块和数字框双向联动，默认 3.0。也可鼠标滚轮 / ↑↓ 键手动滚动；空格键开始/暂停自动滚动。

语音跟读（核心）：点「🎤 在线跟读」并允许麦克风权限，开始朗读后讲稿会自动滚动到您正读到的位置（蓝色基准线处）；当前读到的词会高亮，下一个词淡色提示。跟读中按钮变成「⏹ 停止跟读」，再点一次即退出。

离线跟读（备选）：点「🎧 离线跟读」首次会从网络下载约 40MB 中文模型，之后可断网使用，适合现场无网环境。按钮文案与在线跟读一致（启动中显示「🎧 准备中…」，运行中显示「⏹ 停止跟读」）。

配置导出 / 导入：顶部「⬇ 导出配置」把字体、字号、行距、滚动速度、阅读锚点上下左右、预滚、语速跟随灵敏度、短句拼接、高亮开关、自动重连等一起存成一个小 json 文件；换电脑或换浏览器时点「⬆ 导入配置」选这个文件，所有设置立刻恢复。

逐行横滚：讲稿按句号自动断行，每句话独占一行、不换行。每句的第一个字从十字竖线处开始，然后像一列火车一样连续、匀速地向左滑行——不是读到一个词才挪一格。上下一行的切换也是连续滑过去的。

阅读锚点：点顶部「⚓ 锚点位置」可拖动「上下 / 左右」调整停留位置，也可用 Alt+↑↓←→ 微调（按住 Shift 步长更大），设置会自动记住。

语速跟随：在「⚓ 锚点位置」面板里。调小（例如 10）= 速度几乎恒定，只在你明显变快/变慢时才慢慢跟上，最稳；调大（例如 70）= 语速一变画面立刻跟上，适合即兴讲话。默认 30。

词语高亮开关：顶部「🖍 词语高亮」，可随时开关朗读时的词语高亮（关掉后只保留“当前行更亮”的聚焦效果）。

短句拼接：太短的句子会自动与下一句拼成一行（最多 3 句、且不超过一行宽），避免出现只有几个字的碎行；段落之间不拼接。可在「⚓ 锚点位置」面板里用「短句与下一句拼接同行」开关切换。

语速预测与预滚动：连续朗读几秒后，程序会用实测的推进速度估算你的语速（面板里显示“字/秒”），并按预测位置提前滚动，所以文字是连续滑行而不是一格一格跳；识别结果一更新就立刻按实际语速校正回来。停顿超过 1 秒会自动停止预滚，不会越滚越远。「预滚」滑块控制提前量（0~1.5 秒）。

麦克风说明：在线识别需允许麦克风权限并保持联网。若在应用内预览窗口中使用，浏览器可能拦截麦克风，请用 Chrome/Edge 直接打开 index-v0.16.html；Chrome 的语音服务在部分网络下不可用，可改用 Edge。

⚠ 朗读中还会再问一次？用「本地服务」方式打开（推荐，能彻底消除）：双击 HTML 时地址是 file://，Chrome 把它当成“一个文件”，不会保存麦克风授权；而语音识别会话会被浏览器周期性结束、需要重启，每次重启都可能再问一次。解决办法：双击同目录下的 「启动提词器(推荐-免反复授权).cmd」，它会用系统自带的脚本引擎在 127.0.0.1:8765 起一个本地小服务并自动打开浏览器。第一次点「允许」后浏览器会记住，之后整场朗读都不会再问。那个黑窗口不要关，关掉即停止服务（不影响已打开的页面）。

还可以这样临时缓解：在「⚓ 锚点位置」面板里取消勾选 「断线自动重连识别」——识别断线后不再自动重启，而是停下来等您点「继续跟读」，这样就不会在读的过程中冒出权限窗口。

为什么以前朗读中会反复弹麦克风：旧版在「每次识别断线重启」「设备被占用」「看门狗探活」三处都会主动向浏览器重新申请一次麦克风；而浏览器把 file:// 页面视为不持久化的来源，每申请一次就可能弹一次窗。v0.7 起：整场只在点「在线跟读」时申请一次，之后只重启识别、绝不再碰设备；重启有指数退避和「60 秒最多 25 次」的硬上限，超限会停下并提示点一次「继续跟读」恢复。

麦克风中途失效：朗读过程中如果麦克风被别的程序占用、USB 设备被拔掉、或系统回收了授权，程序会自动重连并继续识别，不需要你手动停止再点一次。工具栏的状态灯会显示「麦克风被占用，稍后重试…」，恢复后回到「识别中…」。

快捷键：空格=自动滚动开关 · ↑/↓=手动滚动 · F=全屏 · R=复位 · Alt+↑↓←→=微调锚点。

分享：本程序是单个 index-v0.16.html 文件，直接发给别人，用 Chrome / Edge 双击打开即可使用，无需安装。如需打包成 .exe，可后续用 Electron 封装（告诉我即可帮你加）。
